# BIND9 DNS Server Hardening

Security hardening project for BIND9 running on Linux.

## Contents

- Hardened BIND9 configuration
- Security hardening checklist
- Attack scenarios
- Testing instructions
- References
- Presentation notes

## Objectives

The objective of this project is to reduce the attack surface of a
default BIND9 installation by applying security best practices.

Main areas:

- Restrict DNS recursion
- Restrict zone transfers
- Hide software version
- Apply least privilege
- Restrict network access
- Enable DNSSEC where appropriate
- Improve logging and monitoring
- Reduce information disclosure
- Keep BIND9 updated
